# PitTools

SBC-Rating-Optimizer für die EA FC Web App — als Userscript + Android-App.

- **Script**: `ea-fc-sbc-optimizer.user.js` (die App lädt es von der Raw-URL
  dieses Repos, Push auf `main` = Update für alle Geräte)
- **Android-App**: `app/` (WebView-Wrapper mit Auto-Update, lädt zusätzlich
  PaleTools Mobile)
- **Doku für Entwicklung**: `CLAUDE.md` (Arbeitsregeln),
  `docs/LEARNINGS.md` (alle Probleme & Lösungen), `docs/ROADMAP.md` (offen)
- **Tests**: `node solver-test.js`
